Settings

Account

Locate the API Section:
Scroll down until you find the section titled
API

Generate the Token:
Click the
Create New API Token
button.
Note:
If you already have an active token, you may need to click
Expire API Token
first to delete the old one before creating a new one.
Download and Save:
This action will automatically download a file named
kaggle.json
.
This file contains your authentication credentials (username and API key).
Crucial Step:
For the API to work, you must move this file to a folder named
.kaggle
in your home directory (e.g.,
~/.kaggle/kaggle.json
on Linux/Mac or
C:\Users\<Windows-username>\.kaggle\kaggle.json
on Windows).
